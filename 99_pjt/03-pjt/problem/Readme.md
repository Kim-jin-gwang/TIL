# 03-pjt

## 프로젝트 소개
Vue.js를 활용한 영화 정보 SPA

## 기술 스택
- Vue 3
- Vite
- Vue Router
- TMDB API / YouTube API

## 설치 및 실행 방법
1. 의존성 설치
   npm install

2. 환경변수 설정
   .env.example을 참고하여 .env 파일 생성 후 API 키 입력

3. 개발 서버 실행
   npm run dev

## 구현 기능
- F01: 최고 평점 영화 목록 조회
- F02: 영화 상세 정보 조회
