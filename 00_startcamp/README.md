# Markdown 기초

간단한 마크다운(Markdown) 안내서입니다. 마크다운은 텍스트 기반의 경량 마크업 언어로, 읽기 쉽고 쓰기 쉬운 형식으로 문서를 작성할 수 있게 해줍니다.

## Markdown이란?

- **정의**: 일반 텍스트에 간단한 기호를 더해 문서 구조(제목, 목록, 코드 등)를 표현하는 문법입니다.
- **장점**: 배우기 쉽고, 어디서나 읽을 수 있으며 HTML로 변환하기 쉽습니다.

## 기본 문법 예시

### 1) 제목

```
# 큰 제목 (h1)
## 중간 제목 (h2)
### 작은 제목 (h3)
```

### 2) 강조

```
*기울임* 또는 _기울임_
**굵게** 또는 __굵게__
```

### 3) 목록

```
- 순서 없는 목록 항목
- 또 다른 항목

1. 순서 있는 목록 첫번째
2. 두번째
```

### 4) 링크와 이미지

```
[Google](https://www.google.com)
![대체 텍스트](https://example.com/image.png)
```

### 5) 코드

인라인 코드: ``print("Hello")``

코드 블록:

```python
def hello():
    print("Hello, Markdown!")

hello()
```

### 6) 인용문

```
> 여기는 인용문 블록입니다.
```

### 7) 수평선

```
---
```

### 8) 표 (간단한 예)

```
| 이름 | 나이 |
| --- | ---: |
| 철수 | 25 |
| 영희 | 22 |
```

### 9) 체크리스트

```
- [x] 완료된 항목
- [ ] 아직 안한 항목
```

## 간단한 작성 팁

- 문단은 빈 줄로 구분합니다.
- 문법은 가능한 간단하게 사용하세요 — 가독성이 가장 중요합니다.
