# 인접행렬
인접 행렬은 그래프와의 연결을 행렬 구조로 나타내는 것이다.
graph[3][3] = [[1, 0, 1], [0, 1, 1], [1, 1, 1]] 일 때, graph[i][j]끼리 이어졌다고 판단하는 것이다.
위의 그래프 값으로 예시를 들면 graph[2][0], graph[0][2], graph[2][1], graph[1][2] 이 4가지의 값이 1이면
각각의 노드끼리 이어졌다고 판단하여 아래의 그래프처럼 그려진다.
graph[i][i] 처럼 행렬이 같은 값일 때는 무조건 이어졌다고 판단해 graph[i][i] = 1로 나타낸다.
0
 \
  1
   \
    2

# 인접리스트
인접 리스트는 그래프의 연결 구조를 리스트 형태로 나타낸다
            1
           / \
          2   3
          | / |
          4---5
위와 같은 그래프가 있을 때 이 그래프를 인접 리스트로 나타내면 각 노드의 인덱스에 어떤 노드가 있는지 값으로 넣으면 된다.
graph[1] = [2,3]
graph[2] = [1,4]
graph[3] = [1,4,5]
graph[4] = [2,5,3]
graph[5] = [4,3]
이런 방식으로 그래프를 나타내는 것을 인접 리스트라고 한다.

# 차이점
인접 행렬은 노드끼리의 연결 여부를 행렬의 값으로 나타낸다는 특징이 있고,
인접 리스트는 연결 여부를 노드의 인덱스 안에 있는 값으로 나타낸다
