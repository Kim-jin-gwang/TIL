3. 자료 구조 Queue에 대한 물음에 답하시오
3-1. 선형 Queue에 값을 삽입, 제거 하는 과정을 설명하시오.
3-2. 위 과정에서 `거짓 포화`가 발생 할 수 있는데 `거짓 포화`는 무엇을 의미하는 것이며, 이를 해결하기 위한 방법을 1가지 이상 설명하시오.


3-1.
선형 Queue는 FIFO(First-in First-out) 구조이다. 값을 삽입하면 0번째 인덱스부터 1,2,3... 순차적으로 쌓이며,
값을 제거 시에는 가장 먼저 들어온 0번째 인덱스부터 순자적으로 삭제된다.

ex)
queue에 1,2,3,4,5 를 삽입할 때,
#1 queue = [1]
#2 queue = [1,2]
#3 queue = [1,2,3]
#4 queue = [1,2,3,4]
#5 queue = [1,2,3,4,5]

queue에서 값을 제거할 때,
#1 queue = [2,3,4,5]
#2 queue = [3,4,5]
#3 queue = [4,5]
#4 queue = [5]
#5 queue = []


3-2.
거짓 포화란 queue가 비어있는데, 꽉 차 있다고 판단하여 queue의 삽입과 삭제 간의 교착 상태가 발생하는 것이다.
해결 방법은 우선순위 큐를 사용하는 것이다.
